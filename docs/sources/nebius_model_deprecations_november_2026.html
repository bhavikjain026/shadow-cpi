Model Deprecations: November 2026

Models soon leaving Token Factory Serverless with recommended migration paths.

On November 9, 2026:
  • Affected Serverless models will no longer be available via API or Playground.
  • Dedicated Endpoints for these models will be unaffected by this change.

​
What to Know

These models will be removed from Token Factory Serverless on November 9, 2026. After that date, you will not be able to select them in the Playground or send API requests using their model IDs.
  • This change only affects Serverless usage. Dedicated Endpoints are unaffected.
  • Token Factory does not automatically reroute requests from deprecated models.
  • Choose a replacement based on your workload, then test before migrating traffic.

Preparing to Migrate

  1. Identify applications and workflows that send requests to a deprecating model ID.
  2. Compare the replacement model’s capabilities, performance and price.
  3. Test prompts, inputs and workloads to verify the new model will work for your use cases.
  4. Update the model and base_url values in your API requests, then verify the results.
Refer to our quick start guide for reference and up to date examples.

​
Consider a Dedicated Endpoint

For production workloads that need stable model versions or custom configurations, consider Dedicated Endpoints, which provide:
  • Control over model versions and deployments.
  • Dedicated capacity and configurable scaling.
  • Workload isolation.
To learn more about Dedicated Endpoints or for help getting started, contact our team: 👉 Contact Token Factory Sales

​
Need Help?

If you need assistance migrating, choosing the right model or getting started with Dedicated Endpoints, our team is ready to help. 👉 Contact Token Factory Support
